# Pantry

A modern recipe management application that helps users discover, save, and organize recipes in one place. Users can browse recipes, easily save their favorites, and create their own personal recipe collection. The backend and storage is secured with Firebase.

## Features

- Browse recipes from an external API
- Save and remove favorite recipes
- Create custom recipes
- Edit custom recipes
- Delete custom recipes
- Responsive design for desktop and mobile
- Cloud storage with Firestore
- User authentication with Firebase Authentication

## Built With

- React
- JavaScript (ES6+)
- Tailwind CSS
- Firebase Authentication
- Cloud Firestore
- Vite

## Challenges

Some challenges that stood out for me:

- Structuring application state as the project grew
- Integrating Firebase Authentication
- Writing secure Firestore Security Rules
- Keeping the UI responsive across different screen sizes
- Managing recipe data from both an external API and user-created recipes

```bash
npm install

```
